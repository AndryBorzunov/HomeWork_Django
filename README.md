# Реализация контроллера с использованием Class-Based Views

1. Все контроллеры переведены с FBV на CBV
2. Создано приложение для блога.
3. Модель блоговой записи имеет поля:
- заголовок,
- содержимое,
- превью (изображение),
- дата создания,
- признак публикации,
- количество просмотров

4. Для работы с блогом реализован полный CRUD, используя CBV
5. Модифицирован вывод и обработка запросов:
- увеличение счетчика просмотров: при открытии статьи счетчик увеличивается на 1
- фильтрация опубликованных статей: в список статей выводятся только те статьи, которые опубликованы
- перенаправление после редактирования: после успешного редактирования записи пользователь перенаправляется на просмотр этой статьи
